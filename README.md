# CyberPunk Neon Dawn

> **Projeto da Disciplina de Computação Gráfica - UERN (2025)**

![Godot Engine](https://img.shields.io/badge/Godot-v4.2-%23478cbf?logo=godot-engine&logoColor=white)
![Status](https://img.shields.io/badge/Status-Em_Desenvolvimento-yellow)

**CyberPunk Neon Dawn** é um jogo de ação 2D do gênero *Beat 'em up* com elementos de RPG, desenvolvido na **Godot Engine**. O jogo combina combate visceral clássico com uma estética Pixel Art Neon e mecânicas de customização cibernética.

---

## Sobre o Projeto

Eyra, uma adolescente ciborgue com uma resistência misteriosa a vírus, precisa atravessar uma megalópole distópica mergulhada no caos. Um novo ciber-vírus está corrompendo implantes e causando surtos de violência na população. O objetivo: chegar ao hospital e ajudar o Dr. Cleyton Raccoon a sintetizar a cura antes que seja tarde demais.

Este projeto foi desenvolvido como requisito avaliativo para a disciplina de Computação Gráfica na **Universidade do Estado do Rio Grande do Norte (UERN)**.

## Mecânicas Principais

* ** Combate Visceral (Hack and Slash):** Sistema de combos fluido com Ataques Leves (rápidos), Pesados (quebra de guarda) e Chutes táticos (controle de grupo).
* ** Sinergias de Implantes (RPG):** Sistema de "circuitos" onde conectar implantes compatíveis desbloqueia habilidades passivas únicas (ex: *Rastro Voltaico*).
* ** Sistema de Sobrecarga (Overdrive):** Mecânica de risco-recompensa onde acumular energia acima de 100% aumenta o dano, mas esgotá-la causa superaquecimento e vulnerabilidade.
* ** Postura e Quebra de Guarda:** Inimigos de elite possuem barras de postura que, ao serem quebradas via *Parries*, permitem execuções cinematográficas.

##  Estilo Visual

* **Pixel Art 16-bit:** Inspirado na era Super Nintendo/Genesis.
* **Iluminação Moderna:** Uso de luzes neon dinâmicas e efeitos de *bloom* para criar a atmosfera Cyberpunk.
* **Interface Diegética:** HUD integrado à visão da protagonista com efeitos de "glitch" digital.

##  Instalação e Execução

Este projeto utiliza a **Godot Engine 4.2** (ou superior).

1.  Clone este repositório:
    ```bash
    git clone [https://github.com/JarysonUERN/Cyberpunk-Neon-Dawn.git](https://github.com/JarysonUERN/Cyberpunk-Neon-Dawn.git)
    ```
2.  Abra a **Godot Engine**.
3.  Clique em **Import** e selecione o arquivo `project.godot` dentro da pasta do projeto.
4.  Pressione **F5** para rodar o jogo.
